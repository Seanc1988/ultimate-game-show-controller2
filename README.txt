THE FEUD LIVE 2.4.0 — HOST PHONE QUICK START

COMPUTER
Extract FULL ZIP, run Start-The-Feud-Live.cmd, launch audience welcome, configure teams/questions, and start the game. Keep the computer, audience window and server open.

PAIR THE HOST PHONE
Publish the updated phone package. Its host-controller.html must be beside buzzer.html (or set a separate full host-controller.html address in the pairing dialog). Click Host phone controller on the computer and scan its PRIVATE QR. This is different from the contestant QR. Never show the private QR to the audience.

ON STAGE
Tap an answer number to reveal. Green means already revealed. Red X adds a strike; Undo fixes the last action. X and Undo stay at the bottom of the phone screen during regular play and steals. The third strike opens the steal. Tap an unrevealed correct answer to award the steal, or X for a missed steal.

FACE-OFF
Phone contestant buzzes appear automatically; the host can also tap a team Buzz button. Choose the team answering, record their numbered answer, hear the other team, then award the face-off to either team. Tap Play or Pass. Face-off no-match X sounds the cue without adding a regular-play strike.

NEXT ROUND
Tap Next round / continue and confirm. Manual pot awards are under More round controls. The computer retains its normal multipliers, target, sudden-death and bonus transitions.

QUICK CASH
Start A; type answers or tap an accepted answer, pass and return. Start B; duplicate answers require a replacement. Pause/resume, duplicate buzzer and hiding A are available. Reveal B answers and the final result, then complete the bonus. For detailed manual score corrections, use the computer.

CONNECTION
Reconnect is on the phone. Disconnected controls lock. A tap with a lost confirmation is not replayed; inspect the updated board before tapping again. Regenerating the private QR or reloading the computer invalidates the old host link. One host phone is active at a time. Real venue phone connectivity still needs testing.

DEPLOYMENT: Upload all files in this folder together. Set the public HTTPS buzzer.html URL on the computer. host-controller.html and signup.html must be alongside it; preserve css, js and assets subfolders. No GitHub upload was performed.
